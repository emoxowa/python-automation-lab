# Python Automation Lab

## О проекте

Учебный проект для практики базовой автоматизации: фильтрация списка заявок и вывод только срочных (`urgent`). Одна и та же логика реализована на Python (`py.py`) и JavaScript (`js.js`).

## Технологии

- Python 3
- JavaScript (Node.js)

## Как запустить

### Python

```bash
python3 py.py
```

Или с виртуальным окружением:

```bash
source .venv/bin/activate
python py.py
```

### JavaScript

```bash
node js.js
```

Ожидаемый вывод в обоих случаях:

```
Ошибка входа
Не проходит оплата
Сервис недоступен
```
